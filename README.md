# PoliceProof 🚔

## From Complaint to Resolution

PoliceProof is a technology-based solution designed to improve
transparency, accountability, and trust between citizens and police.

## Problem

Citizens may face difficulty knowing whether their complaint/FIR
has been submitted, reviewed, assigned, or investigated.

## Solution

PoliceProof provides a digital system where citizens can:

- Submit a complaint
- Receive a unique Case ID
- Track permitted case progress
- See whether their complaint has been submitted
- See whether the case is under review
- Receive permitted status updates

Police officers can:

- Manage assigned cases
- Update case status
- Manage evidence information
- Maintain an activity history
- Review cases through a dashboard

## Key Benefits

- Reduces opportunities for corruption
- Builds trust between citizens and police
- Provides transparency
- Allows citizens to track case progress
- Creates an organized digital record
- Improves accountability
